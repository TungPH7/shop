## 6. Kiến trúc & ranh giới (folder 06)

### Ba tầng — phụ thuộc MỘT CHIỀU `shared → features → app`

- **shared** = hạ tầng tái dùng, ở các thư mục con của `src/`: `lib` (wrapper 3rd-party + http client), `components` (UI dùng chung ≥2 feature), `hooks`, `utils`, `config`, `types`, `stores` (Redux → folder 14), `ui` (Phase 1.2), `i18n` (next-intl routing/navigation/request, folder 09), `testing`. **KHÔNG** được import từ `features`/`app` → giữ tái dùng + chặn vòng lặp.
- **features/&lt;tên&gt;** = một domain nghiệp vụ "ốc đảo"; chỉ import `shared` (+ chính nó). **Cấm import chéo** giữa các feature.
- **app/** = composition root (App Router); nơi DUY NHẤT ghép nhiều feature. Được import cả `features` lẫn `shared`.
- Cần code chung cho 2 feature → **nâng lên `shared`** hoặc **ghép ở `app`**, KHÔNG import feature này từ feature kia. _(Thư mục shared tạo **khi cần**, không tạo rỗng sẵn.)_

### Giải phẫu một feature

| Thư mục             | Nội dung                                                                  | Kích hoạt |
| ------------------- | ------------------------------------------------------------------------- | --------- |
| `model/`            | type + (sau) schema Zod + **logic thuần** (no React/UI/IO) — dễ test nhất | folder 06 |
| `components/`       | UI của feature (Server/Client Component)                                  | folder 06 |
| `server/`           | **server-only** data access (DAL gọi backend) + `import 'server-only'`    | folder 11 |
| `actions/`          | Server Actions (`"use server"`)                                           | folder 12 |
| `hooks/` · `store/` | hook/headless + client state riêng feature (qua facade Redux)             | khi cần   |

> **Hai trục ranh giới — đừng nhầm:** (1) **tầng** `shared→features→app` — enforce NGAY bằng ESLint (dưới). (2) **server/client** — RSC mặc định, đảo "islands" bằng `"use client"`; data access nằm ở `server/` và chốt bằng `import 'server-only'` (folder 07 env, 11 DAL). BFF: `features/<x>/server/` → http client `lib/` → backend; **client KHÔNG gọi backend trực tiếp**.

### Enforce bằng máy (`eslint.config.mjs`)

- **`eslint-plugin-import-x`** `import-x/no-restricted-paths` (error): "zone" sinh từ mảng `SHARED_DIRS` + `FEATURES`. **Thêm feature mới ⇒ thêm tên vào `FEATURES`** (đúng 1 dòng) để có ngay zone cấm chéo.
- **`eslint-import-resolver-typescript`** qua `import-x/resolver-next` (đọc `paths` ở `tsconfig.json`) → boundary "thấy" được import qua alias `~/...`. _Không có resolver thì boundary mù với alias._
- **`import-x/no-cycle`** (error, `ignoreExternal`) — cấm vòng lặp import.
- Luôn import qua **`~/...`** (kể cả trong cùng feature); vẫn áp **kebab-case** + **no-barrel** (folder 03).

## 10. Rendering & Caching — Cache Components (folder 10)

- **Bật `cacheComponents: true`** (top-level `next.config`, 16.2.9 KHÔNG còn experimental; gộp `ppr`+`dynamicIO`+`useCache`). Đổi mặc định TOÀN APP: **dynamic-by-default** (opt-in cache), **PPR mặc định** (prerender static shell + stream dynamic holes; build đánh dấu `◐`). ⚠️ **Static export & edge runtime KHÔNG hỗ trợ** (deploy Node/platform). Client-nav giữ state qua React `<Activity>` (ảnh hưởng UI Phase 1.2). `generateStaticParams` cấm trả `[]`.
- **`'use cache'`** (`next/cache`) ở file/component/**function** → cache giá trị trả về (cache-key = buildId + id hàm + **args**; biến closure tự bắt vào key). File-level: mọi export phải `async`. ⚠️ **Luật cô lập:** trong scope cache KHÔNG đọc request-time (`cookies/headers/searchParams/params`, **`new Date()`/current-time**, random) → đọc NGOÀI, truyền **args** (đọc vào → treo build 50s/lỗi).
- **`cacheLife(profile)`** trong scope cache: `seconds|minutes|hours|days|weeks|max` | custom (`next.config.cacheLife`) | object inline. 3 mốc `stale`(client)/`revalidate`(SWR server)/`expire`(synchronous regen).
