# 14 — Internationalization (i18n)

> Ngôn ngữ hiện tại do i18next sở hữu. Key được kiểm bằng TypeScript. Bản dịch của feature tải lười.

## 14.1 Nguồn sự thật

### IN-001 [MUST] Ngôn ngữ hiện tại chỉ nằm ở i18next

Không sao chép ngôn ngữ sang Redux hay Context — hai bản sao chắc chắn lệch. Việc lưu lại lựa chọn do bộ phát hiện ngôn ngữ của i18next đảm nhiệm, không viết slice riêng.

### IN-002 [MUST] Component đổi/đọc ngôn ngữ qua facade `useLocale()`

`useLocale()` → `{ locale, locales, labels, setLocale }`. Component không gọi thẳng `i18n.changeLanguage`. → `CP-006`

### IN-003 [MUST] Đổi ngôn ngữ không được reload trang

`setLocale` → react-i18next tự re-render cây component.

## 14.2 Chuỗi & key

### IN-004 [MUST] Không hardcode chuỗi hiển thị cho người dùng trong JSX

✅ `<h1>{t('product.title')}</h1>` ❌ `<h1>Danh sách sản phẩm</h1>`

Ngoại lệ: fallback lỗi cấp app cố ý dùng chuỗi tĩnh tiếng Anh (`EH-005`).

### IN-005 [MUST] Key phải type-safe

Augment kiểu của i18next từ file JSON tiếng Anh (bộ key gốc) ⇒ gõ sai key là **lỗi compile**, không phải chuỗi thô hiện lên production.

### IN-006 [MUST] Key đặt theo phân cấp ngữ nghĩa, không theo vị trí trên màn hình

✅ `product.list.empty` ❌ `homeSecondBoxText`

### IN-007 [MUST] Số nhiều và biến dùng cơ chế của i18next

✅ `t('product:count', { count })` với `_one` / `_other` trong file dịch
❌ `count > 1 ? t('products') : t('product')`

### IN-008 [MUST] Bản dịch đặt tập trung theo `locale/namespace`

`src/lib/i18n/locales/<lng>/<ns>.json`. **Không** đặt file dịch trong `features/` — sẽ sinh phụ thuộc chéo feature khi một màn hình dùng chuỗi của nhiều nơi.

Mọi locale phải có cùng bộ key; thêm key mới là thêm cho **tất cả** locale.

## 14.3 Nạp & hiệu năng

### IN-009 [MUST] Namespace `common` nạp sẵn, namespace của feature tải lười

Vỏ app (nav, nút chung) luôn cần ⇒ `common` đi cùng bundle khởi động để không nhấp nháy. Namespace theo feature tách chunk riêng, tải khi vào màn hình đó.

### IN-010 [MUST] Khai bản dịch lười bằng glob tĩnh

Bundler cần phân tích được ở thời điểm build ⇒ dùng `import.meta.glob` với mẫu tĩnh, loại trừ `common`. Không ghép chuỗi động trong `import()`.

### IN-011 [MUST] Hai tầng Suspense

| Tầng | Bọc gì | Bắt gì |
|---|---|---|
| App | Quanh `RouterProvider`, **bên trong** error boundary | Lần khởi tạo i18n đầu tiên |
| Layout | Quanh `<Outlet />` | Namespace tải lười theo trang — vỏ app đứng yên |

### IN-012 [MUST] Không bật escape của i18next

React đã escape sẵn; bật thêm sẽ double-escape (hiện ra `&amp;`).

## 14.4 Nội dung

### IN-013 [SHOULD] Không ghép câu bằng nối chuỗi

✅ `t('cart.summary', { count, total })` với câu hoàn chỉnh trong file dịch
❌ `t('you have') + ' ' + count + ' ' + t('items')` — trật tự từ mỗi ngôn ngữ một khác.

### IN-014 [SHOULD] Định dạng ngày/số/tiền tệ theo locale

Dùng cơ chế định dạng theo locale, không tự ghép `dd/MM/yyyy`.
